# 分析契约

模块没有行为配置项。每次调用都由 `ProjectUnitSourceAnalysisRequest` 完整描述。

## 请求规则

| 输入 | 规则 |
|---|---|
| `WorkspaceRoot` | 必须是已存在目录，并用于计算源码、项目和目录相对路径。 |
| `ProjectPaths` | 可以是绝对路径或工作区相对路径；系统会按不区分大小写的方式规范化、排序和去重。 |
| 外部项目 | 排除并返回 `OutsideWorkspace` 诊断。 |
| 缺失项目 | 返回错误，并把目录标记为部分结果。 |
| 语言 | 仅支持 C# 项目。 |

解决方案发现和测试项目过滤由调用方负责，这样仓库策略不会混入语义分析器。

## 目录字段

每个 `ProjectUnitSourceUnit` 包含：

- 稳定目录键和运行时键；
- 项目、程序集、命名空间、类型和源码位置；
- 与运行时目录相同优先级的 ProjectUnit 分类；
- 显式元数据标题、负责人、描述、标签和需求 ID；
- 作为描述后备来源的 XML 摘要；
- 项目单元的出向与入向依赖；
- 注解格式错误和依赖未解析诊断。

自定义中间基类会通过语义继承关系识别。即使具体类型通过应用自己的基类间接继承，也能解析为对应 Monica ProjectUnit 类型。

## 部分结果

项目加载或编译失败不会丢弃其他成功项目。分析器会返回已发现单元，设置 `IsPartial`，并记录稳定诊断。取消操作抛出 `OperationCanceledException`，由调用方决定是否保留旧快照。

空输入返回空目录，不代表覆盖率为 100%。
