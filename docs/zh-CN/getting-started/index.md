# 开始使用 Monica

这一组页面带你完成一个明确、可验证的 Monica 主机组合。你将只安装应用真正需要的包，并把所有模块放在同一个 `builder.AddMonica(...)` 边界中。

## 你将完成

1. 安装需要的 Stable 包。
2. 注册模块并配置 `ModuleOption` / `ModuleGuide`。
3. 构建 Web 主机，再应用 Monica 中间件与端点。
4. 从运行时界面或接口确认实际加载的模块与项目单元。
